# 📣 Зазывалкин — телеграм-бот-звалка

Тегает всех участников чата по текстовой команде **`калл`**. У каждого свой эмодзи-идентификатор, всё кастомизируется.

Дополнительно **сам** присылает расписание СОШ №46 и пишет, что изменилось.

```
калл                 → пингует всех с заголовком по умолчанию
калл ТЕКСТ           → пингует всех и показывает этот ТЕКСТ
```

Например: `калл собираемся на созвон через 5 минут` — бот выведет этот текст и следом тегнет всех.

## Возможности

- `калл` / `калл ТЕКСТ` (а также `/call`, `call`) — позвать всех
- у каждого свой эмодзи рядом с упоминанием
- `/emoji 🔥` — задать себе эмодзи
- `/setemoji @user 🔥` — админ задаёт эмодзи другому (или ответом на сообщение)
- `/join` / `/leave` — войти/выйти из списка зовущихся
- `/who` — посмотреть список
- `/calltext ТЕКСТ` — админ меняет заголовок по умолчанию
- данные хранятся отдельно по каждому чату в `call_bot_data.json`

## Расписание школы

Сайт: [sosh46.ru/raspisanie](https://sosh46.ru/raspisanie/). Уроки лежат в Google-таблицах на страницах «Изменения», 1–4 и 5–11 классы.

В группе бот делает это сам, команды не нужны:

- с **8:00 каждые 2 часа** проверяет сайт и пишет в чат, **только если появились замены**;
- в **7:30 (UTC+4)** присылает расписание **на сегодня**;
- в **18:00 (UTC+4)** присылает расписание **на завтра**;
- словами: сегодня, завтра, неделя, замены, звонки.

По желанию:

```
класс 10А                # сетка класса на неделю (можно 10А, 10Б)
сегодня / завтра / неделя
замены / звонки
калл
```

## ⚠️ Важное ограничение Telegram

Bot API **не отдаёт полный список участников группы** — это ограничение самого Telegram, обойти его нельзя. Поэтому бот запоминает людей, когда они **пишут что-нибудь в чат** или делают `/join`, и пингует их персональными упоминаниями `tg://user?id=...` (это настоящее уведомление).

## Как проверить

Без Telegram — только парсер сайта (можно класс):

```bash
python3 -m unittest test_schedule_watch.py
python3 schedule_watch.py
python3 schedule_watch.py 8А
```

В Telegram:

1. `export BOT_TOKEN="…"` и `python3 bot.py`
2. Напиши боту в личку `/start`, потом добавь его в группу.
3. У @BotFather: `/setprivacy` → **Disable**.
4. В группе напиши что-нибудь (чтобы запомнил людей) и:
   - `расписание` — что уйдёт в чат как расписание
   - `/schoolcheck` — сразу сходить на сайт (не ждать 8:00 / 10:00 / …)
   - `калл` — зов всех
5. Автопроверка сайта: 8:00, 10:00, 12:00… по UTC+4. Чтобы не ждать слот — `/schoolcheck`.

## Установка

1. Создай бота у [@BotFather](https://t.me/BotFather) и получи токен.
2. У @BotFather отключи Privacy Mode: `/setprivacy` → выбери бота → **Disable**. Иначе бот не видит обычные сообщения в группе и не сможет запоминать людей.
3. Клонируй репозиторий и установи зависимости:

   ```bash
   git clone https://github.com/USERNAME/call-bot.git
   cd call-bot
   pip install -r requirements.txt
   ```

4. Задай токен (любой из способов):

   ```bash
   export BOT_TOKEN="123456789:AA..."   # Linux / macOS
   # setx BOT_TOKEN "123456789:AA..."   # Windows (в новом окне терминала)
   ```

   или скопируй `.env.example` в `.env` и заполни (тогда подгрузи его своим способом, напр. через python-dotenv).

5. Запусти:

   ```bash
   python bot.py
   ```

6. Добавь бота в группу и дай права на чтение сообщений. Готово — пиши `калл`.
